# LeaseCheck 🛡️ (สคบ. 2568)

ระบบตรวจสอบสัญญาเช่าหอพักและห้องเช่าอัตโนมัติ สำหรับระบบปฏิบัติการ Android (Kotlin + Jetpack Compose)

## ความสามารถหลัก (Core Features)

1. **🔍 ตรวจสอบสัญญาเช่า (Contract Inspection)**:
   - ตรวจสอบข้อความสัญญาเช่าเทียบกับเกณฑ์ประกาศคณะกรรมการว่าด้วยสัญญา พ.ศ. 2568 และ พ.ร.บ.หอพัก พ.ศ. 2558
   - จำแนกความเสี่ยงออกเป็น 3 ระดับ:
     - 🔴 **สีแดง (เสี่ยงสูง / ต้องห้าม)**: เช่น ห้ามคิดค่าน้ำค่าไฟเกินอัตราทางการ, ห้ามล็อกห้องยึดทรัพย์สิน, ห้ามริบเงินประกันโดยผู้เช่าไม่ผิด, ห้ามตรวจห้องโดยไม่แจ้ง
     - 🟡 **สีเหลือง (ข้อควรระวัง)**: เช่น เงินประกันเกินเพดาน 3 เดือน, คืนเงินประกันช้ากว่า 7-14 วัน, ซ่อมแซมทุกกรณี, แจ้งย้ายออกนานเกิน 30 วัน
     - 🟢 **สีเขียว (เป็นธรรม)**: สอดคล้องตามประกาศ สคบ.
   - วิเคราะห์ด้วย Google Gemini AI (`gemini-3.5-flash`) ร่วมกับระบบประเมินข้อสัญญาในเครื่อง (Local Rule Engine) รองรับการใช้งานแม้ออฟไลน์
   - ระบบปิดบังข้อมูลส่วนบุคคลอัตโนมัติ (Redact เลขบัตรประชาชน 13 หลัก, เบอร์โทรศัพท์, อีเมล) ก่อนส่งประมวลผล
   - สัญญาตัวอย่างจำลอง 3 รูปแบบ (หอพักบุญอนันต์ - เสี่ยงสูง, หอพักสุขสราญ - ควรระวัง, หอพักกรีนลิฟวิ่ง - มาตรฐาน)

2. **🧮 เครื่องคำนวณส่วนต่างค่าน้ำ-ค่าไฟ และเงินประกัน (Utility & Deposit Surcharge Calculator)**:
   - คำนวณส่วนต่างค่าไฟฟ้าและค่าน้ำประปาที่ถูกเรียกเก็บเกินอัตราทางการ
   - คำนวณเพดานเงินประกันและค่าเช่าล่วงหน้า (ไม่เกิน 3 เดือนของค่าเช่า)
   - แสดงยอดเงินรวมที่ผู้เช่าเสียเปรียบตลอดอายุสัญญา

3. **📖 เกณฑ์ สคบ. และสิทธิผู้เช่า (Legal Criteria & Tenant Rights)**:
   - 10 ข้อห้ามของผู้ให้เช่า ตามประกาศคณะกรรมการว่าด้วยสัญญา พ.ศ. 2568
   - 6 สิทธิของผู้เช่าที่กฎหมายคุ้มครอง
   - ข้อกำหนดเฉพาะสำหรับหอพักที่จดทะเบียนตาม พ.ร.บ.หอพัก พ.ศ. 2558
   - ปุ่มโทรด่วนสายด่วนคุ้มครองผู้บริโภค สคบ. 1166

4. **🕒 บันทึกประวัติการตรวจสอบ (Inspection History)**:
   - บันทึกผลการวิเคราะห์สัญญาเช่าเพื่อเปิดดูย้อนหลังได้ทุกเมื่อ

## สถาปัตยกรรม (Architecture)

- **ภาษา**: Kotlin 2.2.10
- **UI Framework**: Jetpack Compose (Material Design 3)
- **ระบบสร้างแอป**: Gradle Kotlin DSL (AGP 9.1.1, Java 21, Android SDK 36)
- **สถาปัตยกรรมซอฟต์แวร์**: MVVM (Model-View-ViewModel) + Coroutines & StateFlow
- **AI Integration**: Google Gemini API (`v1beta/models/gemini-3.5-flash`)
